Conformadora 2D hasta 8 mm

Diseñada para optimizar la fabricación de piezas industriales, con servomotores en doblado y tracción para un control más exacto del proceso de conformado.

A través de una aplicación sencilla, el usuario define la forma de cada pieza indicando el largo de cada lado y cada ángulo de doblado, y luego cuántas unidades producir de cada una.

Incorpora además una rueda antigiro en el ingreso del alambre, que mantiene el conformado en un mismo plano durante toda la operación y evita que las piezas se tuerzan.
